# Gioco del 15

Gioco del 15 multiplayer locale per Android, con connessione Nearby e puzzle condiviso tra i partecipanti.

## Obiettivi iniziali
- Android nativo in Kotlin
- Activity separate per le macro-schermate
- UI responsive portrait/landscape
- Risorse grafiche separate dal codice
- Componenti riutilizzabili e configurabili
- Motore puzzle indipendente dalla UI
- Multiplayer locale tramite Nearby Connections
